# Backlog funcional recomendado

## Objetivo de este backlog

Proponer la siguiente capa de valor funcional una vez cubierta la base del producto.

No es un compromiso cerrado. Sirve como referencia para priorizacion.

## Prioridad alta

### 1. Datos de ejemplo

Valor:

- facilita demos
- acelera pruebas con negocio
- reduce friccion en el primer uso

### 2. Autenticacion basica

Valor:

- protege la informacion
- prepara el producto para un uso real

### 3. Exportacion de informes

Valor:

- permite compartir resultados
- da salida practica a los informes

Formatos recomendados:

- PDF
- Excel

## Prioridad media

### 4. Importacion desde fichero

Valor:

- evita carga manual repetitiva
- acelera adopcion

### 5. Alertas o avisos de desviacion

Valor:

- convierte el sistema en una herramienta mas proactiva
- ayuda a actuar antes de que el problema crezca

Ejemplos:

- partida supera el 80 por ciento del presupuesto
- gasto variable acumulado por encima del ritmo previsto

### 6. Escenarios de presupuesto

Valor:

- ayuda a planificar alternativas
- permite comparar escenario conservador, realista y optimista

## Prioridad estrategica

### 7. Multi hogar o multi unidad

Valor:

- permite escalar el producto a varios contextos de uso

### 8. Integracion bancaria

Valor:

- reduce carga manual
- mejora actualidad del dato

### 9. Version movil o experiencia responsive mejorada

Valor:

- facilita uso recurrente
- aumenta frecuencia de actualizacion de consumos

## Recomendacion de orden

Si hubiera que elegir un siguiente bloque funcional unico, la recomendacion seria:

1. datos de ejemplo
2. autenticacion basica
3. exportacion de informes
4. alertas de desviacion
