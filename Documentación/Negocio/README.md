# Documentacion orientada a negocio

Esta seccion esta pensada para personas de negocio, producto, analisis funcional o coordinacion de proyecto.

No entra en detalles de implementacion tecnica salvo cuando es necesario para entender una limitacion o una decision funcional.

Objetivos de esta documentacion:

- explicar para que sirve la aplicacion
- dejar claras las reglas funcionales mas importantes
- facilitar demos, validaciones y conversaciones con usuarios
- servir como base para priorizar futuras mejoras
